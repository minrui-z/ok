# Boston 2026 · APSA Field Notes

以 Boston Marriott Copley Place 為基地的互動式旅程手冊，整理 9/1–9/12 的航班、APSA 發表、Boston 市區、Salem、Newport、租車與 New Balance 總部周邊行程。

## 網站功能

- 10 天逐日時間軸與地圖捷徑
- APSA 發表時段、往返交通與緩衝時間
- Salem 與 Newport 兩套租車安排
- New Balance 總部可參觀範圍與交通說明
- 景點照片、圖片出處與授權頁面連結
- 訂位清單、預算概算、行李勾選清單
- 深色模式、手機底部導覽、鍵盤操作與減少動態效果支援

## 本機啟動

需要 Node.js `>=22.13.0`。

```bash
npm install
npm run dev
```

## 驗證

```bash
npm run lint
npm test
```
